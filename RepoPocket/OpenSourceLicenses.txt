# Pinned decoder sources

- zstd v1.5.7, commit `f8745da6ff1ad1e7bab384bd1f9d742439278e99`: decoder-only amalgamation generated by upstream `build/single_file_libs/create_single_file_decoder.sh`; upstream LICENSE retained.
- XZ Embedded commit `ae63ae3a36ed01724674e8f3d750dc47bf125410`: userspace decoder, CRC32/CRC64/SHA256 enabled, 0BSD COPYING retained. No subprocesses, encoder or external runtime library.

Wrapper review: one complete frame/stream, no trailing bytes; 32 MiB output and dictionary/window caps; checksum validation provided by upstream decoders. Unsupported XZ filters/checks fail closed. Apple Compression LZMA is not used: its raw LZMA interface is not a general checked XZ container decoder. This is a source review and pinned dependency, not a claim of independent security certification.
