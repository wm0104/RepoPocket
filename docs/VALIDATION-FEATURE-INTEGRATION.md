## 功能分区

1. deb 编辑信息：版本与完整描述、空段落、当前版本日志、独立发布日期；安全副本与生成后重读验证。
2. 导航与提交发布：取消提交/发布 Tab、撤销 TrollFools 专用产品能力；上传归代码页，发行版归发行版管理，外部文件按上下文选择去向；deb 保存回填和统一预检确认。
3. 工作流：读取选定分支真实 `workflow_dispatch.inputs`，原生表单、默认值、必填/类型/选项校验、参数确认，读取失败不启动，结果未知不自动重发。
4. 本地 Git：复用现有差异和分支同步，补齐独立暂存/取消暂存/仅提交已暂存内容；常见本地合并冲突的持久解决闭环；revert，移除最新未推送普通提交，压缩顶部连续未推送普通提交；恢复引用和保守远端确认。
5. 本地导入和关联：当前目录统一添加入口；缺远端时就地关联，不自动同步。

## 明确不做

- 删除中间提交、交互式 rebase、cherry-pick、自动强制推送。
- 自动上传、静默丢弃改动或覆盖原始 deb。
- 删除远端 TrollFools 仓库/软件源/文件；TrollStore 安装与更新能力不属于 TrollFools 移除范围。
- 全 App 换皮、重做无关动画或重新引入旧 Workspace 产品入口。
