## 登录修复

- 修复首次登录勾选“社交账号管理”后错误提示账号不同的问题。
- 修复添加其他 GitHub 账号时被当前账号身份误拦截的问题；保留已有账号补授权的身份校验和权限检查。

## 工作流体验

- 在运行详情增加摘要入口，展示真实摘要的文字、表格和链接，复用现有正文放大、缩小功能。
- 摘要无法直接读取或需要网页登录时，可通过内置浏览器查看 GitHub 原始摘要。
- 精简默认展开的信息，将次要说明收进运行详情，沿用原有折叠交互。
- 将运行日志的加载提示移至页面顶部，不再显示在页面中间。

## 自动发布

- 完整构建成功且版本号高于已有正式发行版时，自动发布经过校验的安装包与对应更新说明。
- 版本号未提升时不重复发布；测试、构建、产物或更新说明校验失败时不发布。
